# text2me — сайт-концепт

Обновлённый статический сайт: три пути к задаче (по ситуации, по названию документа, через AI-путь), отдельный ряд инструментов, шесть основных аудиторий и страница «Моё пространство».

## Просмотр онлайн

https://rytikov0285.github.io/text2me/

## Страницы

- Главная: три пути начала, быстрый поиск, популярные названия документов, каталог категорий, инструменты, аудитории.
- `people/` — материалы для граждан.
- `business/` — деловые документы для предпринимателей и организаций.
- `documents/pretenziya-prodavtsu/` и `documents/isk-v-sud/` — примеры документов и сценариев.
- `prompts/` — каталог задач и инструментов.
- `knowledge/` — база знаний и официальные источники.
- `space/` — концепт личного пространства для документов, коллекций и ссылок.
- `assets/style.css` — адаптивные стили.
- `assets/main.js` — поиск, быстрые чипы, маршрутизация формы ситуации и демонстрационный AI-путь.
- `sitemap.xml`, `robots.txt` — файлы для поисковых систем.

## Статус функций

Это статический прототип. Каталог на главной показывает стартовые направления, а не подтверждённое число шаблонов. Форма претензии формирует текст в браузере. AI API, вход, облачное сохранение, серверная генерация DOCX/PDF, электронная подпись и реальная онлайн-обработка PDF пока не подключены. На странице «Моё пространство» кнопка входа намеренно отключена и объясняет текущий статус.

Рекламные тексты используют рекламный подстиль публицистического стиля: показывают пользу и следующий шаг, но не содержат выдуманных отзывов, количества пользователей, обещаний юридической гарантии или заявления о проверке юристами без подтверждения.

## Проверка перед публикацией

1. Проверить все маршруты на GitHub Pages.
2. Проверить адаптивность, клавиатурную навигацию и работу поиска на телефоне и компьютере.
3. Подключать аккаунты, хранение и формы отправки данных только после определения архитектуры безопасности, сроков хранения и правовых оснований.
4. Подключать AI API и инструменты PDF/подписи только после реализации и тестирования, не выдавая демонстрационные ссылки за работающие сервисы.
5. Перед коммерческим запуском провести юридическую проверку содержимого и требований к персональным данным.
