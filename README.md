# text2me — статический прототип сервиса документов

Онлайн: https://rytikov0285.github.io/text2me/

## Навигация и возможности

- Главная: компактное рабочее пространство в стиле офисного приложения; панель команд, доступные конструкторы, библиотека документов и навигация по материалам.
- `people/`, `business/`, `knowledge/`, `prompts/` — разделы по аудиториям, задачам и источникам.
- `data-engine/` — статус и первый коннектор мониторинга официальной выгрузки ГАР/ФИАС.
- `documents/pretenziya-prodavtsu/`, `documents/isk-v-sud/` — локальные конструкторы черновиков.
- `space/` — локальное хранилище документов и черновиков, коллекции, теги, архив, поиск, резервное копирование и загрузка документов из файла (резервная копия или CSV из Excel).
- `privacy/`, `security/`, `terms/`, `updates/` — правила и журнал изменений.
- `assets/style.css` и `assets/enhancements.css` — базовая и единая адаптивная дизайн-система, включая компактную панель инструментов главной страницы.
- `assets/main.js` — поиск, маршрутизация ситуации и генерация черновиков.
- `assets/enhancements.js` — локальное автосохранение, экспорт DOCX, печать в PDF, диалоговый навигатор, фильтры, обратная связь и пространство.

## Статус функций — важно

- **Работает локально:** три конструктора черновиков, текстовый экспорт, создание DOCX в браузере, печать/сохранение в PDF через браузер, автосохранение некоторых форм, пространство и скачивание резервной копии, импорт резервной копии и CSV UTF-8.
- **Демо:** диалоговый навигатор задаёт до двух уточняющих вопросов и направляет в раздел по заранее заданным правилам. Это не подключённая генеративная AI-модель.
- **Не реализовано:** аккаунты, облачное сохранение и синхронизация, серверная генерация, прямая загрузка XLSX, полноценные интеграции с CRM/API и отправка обратной связи владельцу сайта. Импорт из Excel работает через CSV.
- **Движок справочников:** добавлен первый коннектор проверки официального источника ГАР/ФИАС; до успешного запуска GitHub Actions он не считается проверенным. Поисковый адресный индекс и интеграция с формами пока не реализованы. На первом этапе платные API не используются.
- **Юридические ограничения:** черновики не являются индивидуальным юридическим заключением. Актуальность права, применимость шаблона и факты требуют проверки.

## Проверка перед публикацией

Проверить маршруты, мобильные размеры, клавиатурную навигацию, скачивание DOCX в Microsoft Word/LibreOffice, печать в PDF, импорт/экспорт JSON и CSV, восстановление черновиков и работу localStorage в целевых браузерах. Правовые страницы и обработку данных необходимо проверить перед коммерческим запуском.

## Источники для проектирования интерфейса

- [GOV.UK: Writing for user interfaces](https://www.gov.uk/service-manual/design/writing-for-user-interfaces) — короткие подписи, привычные пользователю слова, один смысл на фразу, понятные названия ссылок.
- [Microsoft Fluent 2: Content design](https://fluent2.microsoft.design/content-design/) — показывать нужную информацию в момент принятия решения, делать следующие действия очевидными, использовать активный залог и простой язык.
- [Google Docs](https://workspace.google.com/products/docs/) — начинать с шаблона или готового блока, а не заставлять пользователя строить документ с нуля.
- [Canva Docs](https://www.canva.com/create/documents/) — каталог шаблонов и рабочая область для разных типов текстов.
- [Webix Document Manager](https://docs.webix.com/docmanager__userguide.html) — поиск в верхней панели, доступ к недавним файлам, избранному, папкам и архиву.

Эти источники используются как ориентиры для навигации и сценариев. Их функции не считаются реализованными в text2me, пока они не работают в коде.


## Поиск и доступность для поисковых систем

- Публичные содержательные страницы перечислены в `sitemap.xml`; форма обращения и личное рабочее пространство исключены из индекса через `noindex`.
- Главная страница использует уникальные title/description, семантический текст и JSON-LD `WebSite`/`WebPage`. Разметка должна соответствовать видимому содержимому.
- `llms.txt` — дополнительная краткая карта для систем, которые её читают; это не официальный стандарт Google и не гарантия цитирования.
- **Ограничение GitHub Pages:** у проекта адрес с подпутём `/text2me/`, поэтому файл репозитория `robots.txt` публикуется по адресу `/text2me/robots.txt`, тогда как стандартные роботы обычно запрашивают `/robots.txt` в корне хоста. Без собственного домена или контроля над корнем `rytikov0285.github.io` нельзя гарантировать настройку корневого robots.txt. Sitemap доступен отдельно и его можно подать вручную в Google Search Console.
- Для проверки фактического индексирования нужно подтвердить сайт в Google Search Console, отправить sitemap и проверять важные URL через «Проверка URL». Публикация файлов сама по себе не гарантирует индексирование.

## Автоматический мониторинг и сборка ГАР/ФИАС

- `data-engine/fias_connector.py` — единый плановый коннектор, который проверяет официальный источник ФНС и валидирует новый ZIP.
- Workflow `.github/workflows/gar-fias-connector.yml` запускается по расписанию и вручную. При успешной сборке SQLite-файл сохраняется как временный артефакт GitHub Actions.
- `scripts/validate-reference-data.mjs` проверяет структуру реестра и статусы подключения; `.github/workflows/validate-reference-data.yml` запускает структурные проверки, Python-тесты и синтетический тест сборки/поиска.
- Статус в `data-engine/status.json` не означает, что поисковый API уже опубликован. Полная выгрузка ещё не импортирована в постоянное хранилище, и формы сайта не подключены к базе.

## Проверка и сборка ГАР/ФИАС

- `data-engine/fias_connector.py` — единый официальный коннектор, запускаемый по расписанию workflow `.github/workflows/gar-fias-connector.yml`.
- Коннектор проверяет официальный источник ФНС, выбирает ZIP, считает SHA-256, проверяет ZIP CRC и при заданном `GAR_INDEX_OUTPUT` запускает SQLite-сборщик.
- `scripts/build-gar-index.py` читает XML потоково из ZIP и создаёт адресные объекты, дома и иерархии; `scripts/search-gar-index.py` предоставляет локальный JSON-поиск по собранной базе.
- Успешная сборка сохраняется как временный артефакт GitHub Actions; база пока не опубликована как постоянный API и не подключена к формам Text2me.
- Ограничение среды: коннектор принимает архивы до 10 GiB. Полная выгрузка может превышать доступный объём стандартного GitHub-hosted runner; в таком случае сборка завершается ошибкой и не заменяет предыдущую базу. Реальная полная выгрузка ещё не импортирована.
- `scripts/test-build-gar-index.py` проверяет синтетическую ZIP-выгрузку, поиск адреса и дома и сохранение прежней базы при неудачном обновлении. Это тест сборщика, не доказательство проверки реальных данных ФНС.
