# text2me — сайт-концепт

Обновлённый статический сайт с тремя путями к задаче: по ситуации, по названию документа и через демонстрационный AI-путь. Главная включает отдельную строку инструментов, стартовый каталог типов документов, шесть основных аудиторий и страницу «Моё пространство».

## Просмотр онлайн

https://rytikov0285.github.io/text2me/

## Основные страницы

- Главная: три пути начала, поиск по названию, популярные чипы, каталог документов, инструменты, аудитории и кнопка «Наверх».
- `people/` — материалы для граждан.
- `business/` — деловые документы для предпринимателей и организаций.
- `documents/pretenziya-prodavtsu/` и `documents/isk-v-sud/` — примеры документов.
- `prompts/` — каталог задач и инструментов.
- `knowledge/` — база знаний и официальные источники.
- `space/` — предварительный экран личного пространства.
- `assets/style.css` — адаптивные стили.
- `assets/main.js` — поиск по названию, быстрые чипы и передача текста из AI-пути в форму ситуации.
- `sitemap.xml`, `robots.txt` — технические файлы для поисковых систем.

## Статус функций

Это статический прототип. Каталог на главной — стартовая подборка, а не подтверждённое число шаблонов. Форма претензии формирует черновик в браузере. AI API, вход, облачное сохранение, серверная генерация DOCX/PDF, электронная подпись и онлайн-обработка PDF пока не подключены. На странице «Моё пространство» вход явно обозначен как будущая функция.

Рекламные тексты используют рекламный подстиль публицистического стиля: подчёркивают пользу и следующий шаг, но не содержат выдуманных отзывов, числа пользователей, обещаний юридической гарантии или заявления о проверке юристами без подтверждения.

## Проверка перед публикацией

1. Проверить маршруты и переходы на GitHub Pages.
2. Проверить адаптивность, клавиатурную навигацию и поиск на телефоне и компьютере.
3. Подключать аккаунты, хранение и отправку данных только после определения архитектуры безопасности, сроков хранения и правовых оснований.
4. Подключать AI API и инструменты PDF/подписи только после реализации и тестирования.
5. Перед коммерческим запуском провести юридическую проверку содержимого и требований к персональным данным.
