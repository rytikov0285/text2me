# text2me — обновлённый сайт

Обновлённый статический сайт в синем стиле сервисного портала, вдохновлённый удобством Госуслуг без копирования фирменного оформления.

## Просмотр онлайн

https://rytikov0285.github.io/text2me/

## Локальный запуск

В корне проекта выполните `py -m http.server 8000` и откройте http://localhost:8000.

## Страницы

- Главная и поиск
- Для людей
- Для бизнеса
- AI-помощник (демонстрационная страница)
- База знаний
- Пример документа: претензия продавцу

Это статический прототип. Серверная генерация документов, аккаунты, платежи и AI API пока не подключены.
