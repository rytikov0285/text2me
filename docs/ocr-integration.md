# OCR для загрузки документов

## Что реализовано в репозитории

- В окне «Загрузить / сфотографировать» для изображений добавлена явная кнопка «Распознать текст».
- Поддерживаются изображения JPG, PNG, WEBP и GIF размером до 5 МБ. PDF, DOCX и другие документы пока не распознаются.
- Результат показывается в редактируемом текстовом поле. Пользователь может скопировать его или добавить в последнее выбранное текстовое поле формы.
- Ничего не подставляется автоматически без отдельного действия пользователя.
- Клиентская конфигурация — `window.TEXT2ME_OCR_ENDPOINT` в `assets/dadata-config.js`. Сейчас она пустая, поэтому OCR в опубликованной версии не активен.
- Серверный обработчик — маршрут `/ocr` в `integrations/dadata-worker.js`.

## Развёртывание

1. В Google Cloud создайте/выберите проект, включите Cloud Vision API и настройте биллинг согласно условиям Google.
2. Создайте API key для Vision API. Ограничьте ключ только Cloud Vision API; не помещайте его в HTML, JavaScript, GitHub или чат.
3. Разверните `integrations/dadata-worker.js` как Cloudflare Worker. Для DaData задайте существующие секреты `DADATA_API_KEY` и переменную `ALLOWED_ORIGIN=https://rytikov0285.github.io`.
4. В Cloudflare Worker Secrets добавьте `GOOGLE_CLOUD_VISION_API_KEY`.
5. **До открытия OCR для посетителей настройте Cloudflare rate limiting / правила защиты от злоупотреблений для маршрута `/ocr`, лимиты расхода и оповещения Google Cloud.** Проверка Origin нужна для браузерного CORS, но сама по себе не защищает публичный API от прямых HTTP-запросов.
6. Разверните Worker и проверьте `POST /ocr` тестовым изображением. Не отправляйте документы реальных людей при первичной проверке.
7. В `assets/dadata-config.js` задайте публичный адрес `window.TEXT2ME_OCR_ENDPOINT = "https://YOUR-WORKER.workers.dev/ocr";`. Указывайте только URL, никогда — ключ.
8. Опубликуйте сайт и проверьте тестовую фотографию, ошибку неподдерживаемого файла, изображение без текста, отсутствие конфигурации и лимит размера.

## Ограничения и приватность

- Для распознавания содержимое изображения отправляется Google Cloud Vision через ваш серверный Worker только после нажатия «Распознать текст». Без этого действия файл остаётся в браузере.
- Не сохраняйте изображения или OCR-результаты в логах Worker. Не сохраняйте результат в локальном хранилище автоматически.
- Пользователь должен проверить распознанный текст вручную. OCR может ошибаться в ФИО, адресах, датах, номерах и суммах и не удостоверяет подлинность документа.
- Для PDF нужен отдельный поток обработки: например, контролируемая конвертация страниц в изображения либо Google Document AI. Текущий маршрут PDF не принимает.
- Не считать интеграцию рабочей, пока Worker не развёрнут, ключ не настроен, ограничение запросов не включено и реальный тест не пройден.
