Политика конфиденциальности

Какие данные обрабатывает статическая версия text2me и где сохраняются черновики.

1. Текущий режим работы

Эта версия text2me размещена на GitHub Pages. Собственного серверного API, учётных записей и облачного хранилища документов в текущем прототипе нет.

2. Данные, вводимые в формы

Автосохранение форм и документов использует локальное хранилище браузера на вашем устройстве. Карточки участников документов (название, адрес и ИНН), если вы явно сохраняете их в форме, также хранятся только в этом браузере. Они не синхронизируются с другими устройствами и не отправляются на сервер этой страницы.

Карточку можно удалить кнопкой «Удалить карточку» в соответствующей форме. Все локальные данные сайта также могут быть удалены очисткой данных сайта, сбросом браузера или настройками приватности. Не сохраняйте ИНН на общем или чужом устройстве.

Не вводите пароли, коды подтверждения, полные платёжные реквизиты и иные сведения, которые не нужны для черновика. До отправки текста стороннему сервису проверяйте его условия и политику обработки данных.

3. Распознавание изображений

Если функция OCR будет активирована и пользователь отдельно нажмёт «Распознать текст», выбранное изображение будет передано через серверный шлюз внешнему сервису Google Cloud Vision для обработки. Не нажимайте эту кнопку для конфиденциальных документов, если не согласны с передачей изображения поставщику сервиса. Результат показывается в браузере и не сохраняется автоматически. На момент публикации кода адрес OCR-сервиса по умолчанию не настроен; функция не считается активной до отдельного развёртывания.

4. Форма сложной задачи

Форма на странице «Сложный вопрос или задача» формирует текст обращения в браузере. Пока адрес получателя не настроен, содержимое не отправляется на сервер и не сохраняется в базе сайта. Пользователь может скопировать текст или скачать его как TXT-файл. При последующем подключении email или мессенджера данные будут передаваться выбранному внешнему сервису только по действию пользователя.

5. Технические данные

Платформа хостинга может обрабатывать технические сведения о запросах в соответствии с собственными правилами. Эта страница не заменяет политику GitHub Pages и не утверждает, что технические журналы хостинга отсутствуют.

6. Аналитика использования задач

На текущем этапе нажатия на отдельные ссылки задач могут записываться в локальное хранилище браузера: идентификатор задачи, путь ссылки и время нажатия. Эти записи остаются в данном браузере и не позволяют получить общую статистику посетителей.

Перед включением удалённого сбора событий оператор должен настроить аналитический сервер, определить срок хранения, проверить применимые требования и обновить эту политику. В предусмотренной серверной схеме передаются только идентификатор задачи и внутренний путь страницы; содержимое документов, формы, имя и контактные данные не передаются.

7. Ваш выбор

Вы можете не использовать автосохранение, удалить сохранённые документы в разделе «Моё пространство» или очистить локальные данные сайта в настройках браузера. Не загружайте документы с персональными данными, если не понимаете, где они будут храниться.

8. Статус документа

Это информационная политика для прототипа, а не подтверждение юридического соответствия конкретной юрисдикции. Перед публичным коммерческим запуском её необходимо проверить с учётом оператора, инфраструктуры, состава данных и применимого права.
